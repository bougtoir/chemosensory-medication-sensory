# 86 — Journal decision tree (final)

Status: **FINAL FREEZE**. Publication strategy decided by result pattern
(`85`), not by post-hoc appeal.

```
Pattern A (consistent, incl. formulation gradient)
  └─► human-genetics / pharmacogenetics journal
      (e.g. Clin Pharmacol Ther, Pharmacogenomics J, Hum Mol Genet tier)
      framing: "independently-derived chemosensory model predicts
      population medication-exposure patterns"

Pattern B (partial / high-evidence subset)
  └─► pharmacogenetics or genetic-epidemiology specialty journal
      framing: pre-specified panel, transparent calibration result

Pattern C (scattered / controls positive)
  └─► genetic epidemiology methods-aware venue
      framing: association present but sensory-channel interpretation
      rejected by own controls — publish the falsification structure

Pattern D (powered null)
  └─► rigorous-null or specialty venue; preprints allowed
      framing: Level-4 negative result with calibration of the evidence
      framework itself (score vs outcome ρ)

Pattern E (uninterpretable)
  └─► do not submit association claims; report feasibility + framework only
```

## Nature-level convergence requirement (frozen)
Strongest-tier claims require CONVERGENCE of: directional prospective
prediction + continuous cross-prediction calibration + genotype×exposure
gradient + null negative controls + robustness to indication/ancestry
adjustment + effects in more than one pharmaceutical context. An isolated
significant SNP–drug association is never described as proof of the
general framework (patterns beyond A default to specialty venues).

## Frozen commitments
1. The sensory chain S1 was not measured — this limitation is mandatory in
   every abstract and discussion, regardless of pattern.
2. Results are reported as the full panel (predictions + controls +
   calibration), never cherry-picked predictions.
3. Preprint deposit is permitted before journal submission in all patterns.
4. No journal is chosen for prestige beyond fit; the frozen framing text
   above binds each pattern.
