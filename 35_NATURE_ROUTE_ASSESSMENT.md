# 35 — Nature Route Assessment (post-expansion)

Maximum defensible future claim levels:

| Level | Claim | Status after expansion |
|-------|-------|------------------------|
| 1 | Taste receptor variants influence pharmaceutical sensory perception | Supported (dry evidence) |
| 2 | Chemosensory genetics generalizes across foods and medicines | Partially supported |
| 3 | Ancient variation structures responses to modern chemical environments | Plausible; requires population validation |
| 4 | **Population medication behavior can be prospectively predicted from chemosensory biology** | **The validation target** — a positive calibration + ordered-gradient result would support it |
| 5 | The interface is environmentally modifiable | Out of scope (adult bitter plasticity insufficient) — NOT a requirement |

Route if validation succeeds: mechanistic anchor (TAS2R38 architecture,
replicated) + independently frozen prediction panel + population-level
calibration test is a plausible **Nature Communications / Science
Advances** package; **Nature/Nature Medicine** only if the calibration
result is strong across the full panel with clean negative controls and
the Level-3 evolutionary framing is made primary. **Clinical
Pharmacology & Therapeutics / Chemical Senses** remain realistic
fallbacks. The dry package itself (framework + frozen predictions +
feasibility audit) is publishable as a protocol/methods paper.
