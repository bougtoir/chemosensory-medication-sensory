# 25 — Manuscript architecture

1. Drug response is heterogeneous and poorly explained.
2. Chemosensory receptors are chemical sensors expressed in and beyond the oral cavity.
3. Chemosensory phenotype has genetic and acquired components (S = f(G, E)).
4. If the interface contributes to drug-related behaviour, medication patterns contain a chemosensory component (M = g(S, D)).
5. Predictions were frozen before population data (timestamped archive).
6. Test in a two-wave population cohort with longitudinal medication change.
7. Negative controls and formulation/route structure test specificity.
8. FFQ phenotypes triangulate sensory biology.
9. If supported: a modifiable sensory interface is a candidate future target — stated as a hypothesis for intervention research, not a finding.

## Claim levels
Direct (testable here): genotype–medication-change association; formulation gradient; FFQ association. Indirect: chemical-surveillance biology from literature and receptor expression — "compatible with". Not tested: immune causation, sensory plasticity, conditioning, response modification, intervention efficacy, economic or global-health benefit.

## Publication rules
Neutral endpoint terminology (`06`); numbers injected from generated result files; no repository paths or editing history in manuscript text; claims calibrated to the pattern assigned by `85`.
