# 28 — Health-economic and global-health model (not tested in ToMMo)

Conditional hypothesis: if a modifiable sensory component of medication behaviour were shown and an intervention proved effective, low-cost generic/off-patent drugs could remain usable for more patients, with potential cost and public-health benefits. Each step requires its own evidence (intervention trials, cost-effectiveness analyses). This study provides no health-economic or global-health estimate and none will be reported.
