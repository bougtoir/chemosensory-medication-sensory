# 09_META_ANALYSIS

## A. TAS2R38 -> PROP/PTC perception, Fisher combined P
- k = 8 independent studies/cohorts (incl. 1 informative null on a non-cognate drug)
- chi2(16) = 588.7, combined P = 0
- Interpretation: the genotype->S1 arrow for TAS2R38-ligands is beyond doubt.

## B. Effect-direction synthesis, all curated genotype->S1 findings
- positive findings: 24, negative/null findings: 4; sign test P = 9e-05

## C. Why no pooled effect size
Suprathreshold gLMS, detection thresholds, recognition thresholds, taster-class frequencies are NOT pooled into a single effect size (spec rule). Pooled ES meta-analysis not defensible; p-combination + direction synthesis used instead.

## Small-study effects
Not assessable: the literature is dominated by one locus (TAS2R38) and
phenotype scales differ. This asymmetry is itself reported as a risk (F6).
