# 85 — Interpretation matrix (final freeze)

Status: **FINAL FREEZE**. Every possible result pattern maps to exactly one
pre-committed interpretation. Decided BEFORE any result is seen.

| Pattern | Result signature | Pre-committed interpretation | Publication claim level |
|---|---|---|---|
| **A — consistent** | directional tests support frozen signs; controls null; formal G×E gradient test significant in frozen direction (or ordering broadly compatible per `95`); contrasts in-mask | sensory-channel population signature present; hypothesis supported at Level 4 (population-level prediction) | "genotype predicts formulation/exposure pattern consistent with a taste-mediated channel" |
| **B — partial** | subset supports (esp. highest-score predictions) and controls behave; ordering imperfect | sensory signature detectable where evidence was strongest; evidence framework partially validated | "support concentrated in pre-specified high-evidence predictions" |
| **C — scattered** | positives appear but controls also positive, or no EX ordering | associations exist but NOT interpretable as sensory; possible pleiotropy/confounding | "associations observed but mechanistic interpretation not supported" |
| **D — null** | no directional support, controls null | hypothesis not supported at population level in this cohort/design | "no detectable population signature" (informative null only for adequately powered tests) |
| **E — uninterpretable** | primary outcomes unobservable or underpowered | design could not test; no inference drawn | report as unexecuted, with reasons |

## Frozen rules
1. Pattern is assigned by the pre-registered rule, not chosen post hoc:
   evaluate F-PRIMARY verdicts → F-GRADIENT → controls → EX ordering,
   in that order.
1b. A significant isolated SNP–drug association without gradient support
   is NEVER "proof of the general framework" (Amendment 4/nature criteria).
2. Underpowered tests are excluded from pattern assignment (they are
   UNDEFINED, per `73`/`83`), and their count is reported.
3. Pattern C does NOT become A by reinterpreting controls; if needed, an
   amendment (`88`) is required.
4. Level-5 claims ("gene causes medication use") are prohibited in ALL
   patterns (`16`, `75`).
