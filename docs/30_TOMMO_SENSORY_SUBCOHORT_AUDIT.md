# 30 — Sensory Subcohort Audit (public documentation)

Publicly documented sub-measurements:

- Community Support Center physiological exam (~26K): audiometry,
  vision, oral health exam, carotid ultrasound, bone density, ECG,
  vascular, respiratory. (megabank.tohoku.ac.jp/english/sample/)
- Touchscreen questionnaire (~26K): includes self-diagnosis tests,
  oral health questions.
- Oral specimens: plaque from ~25K.

**Taste phenotype measurements:** NOT documented publicly.
**Olfactory testing:** NOT documented publicly.
**Sensory-receptor addon studies:** none found in public materials.
**Genotype overlap:** whole-genome genotyping exists cohort-wide
(67K WGS release 2026/04 per dbTMM press note); TAS2R38 rs713598 is a
common SNP expected on the genotyping backbone, but chip coverage is
LIKELY not CONFIRMED — must be verified in the dbTMM variable catalog
before any data request.

Conclusion: genotype → measured-sensory validation inside ToMMo is
**NOT TESTABLE** from publicly documented instruments. The chain must
be tested via genotype → medication/dietary behavior directly, with
external sensory evidence supplying the mechanistic link.
